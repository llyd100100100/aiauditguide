# AI-Audit-Reviewer 사용 가이드 (Walkthrough)

**AI-Audit-Reviewer** 프로토타입 설치를 완료하셨습니다!
이 문서는 웹 인터페이스(Streamlit)를 처음 사용하시는 분을 위한 간단한 설명서입니다.

## 1. 시작 화면
앱을 실행(`streamlit run app.py`)하면 브라우저에 다음과 같은 화면이 나타납니다.

### 왼쪽 사이드바 (설정창)
화면 왼쪽의 회색 영역은 **입력 및 설정** 공간입니다.
1.  **Gemini API Key**: 구글 AI를 사용하기 위한 암호를 입력하는 곳입니다. (없어도 '데이터 미리보기'는 가능합니다.)
2.  **Upload Audit Log**: 분석할 파일을 올리는 곳입니다. `Browse files` 버튼을 누르거나 파일을 드래그해서 놓으세요.
    *   *테스트용으로 아무 CSV나 엑셀 파일을 올려보세요.*

### 메인 화면 (결과창)
화면 오른쪽의 넓은 영역은 **결과를 보여주는** 공간입니다.
1.  **Data Preview (데이터 미리보기)**:
    *   파일을 올리면 데이터가 표 형태로 보입니다.
    *   **🔴 Original (Local Only)**: 원본 데이터를 보여줍니다.
    *   **🟢 Anonymized (Safe for AI)**: AI에게 보내기 전, 이름/IP가 마스킹된 상태를 보여줍니다. 이 버튼을 눌러보시면 `<PERSON>`, `<IP_ADDRESS>` 처럼 변한 것을 확인할 수 있습니다.
2.  **AI Analysis (분석 결과)**:
    *   API 키를 입력하고 `Analyze with Gemini 3.0` 버튼을 누르면, AI가 분석한 보고서가 여기에 표시됩니다.

## 2. 간단 실습 (따라해보기)
1.  왼쪽 사이드바에서 `Browse files`를 클릭하여 PC에 있는 엑셀/CSV 파일을 하나 선택합니다.
2.  메인 화면에 데이터가 뜨는지 확인합니다.
3.  `Anonymized` 옵션을 선택하여 이름이나 숫자가 가려지는지 확인합니다. (보안 기능 검증)
4.  (API 키가 있다면) 키를 입력하고 `Analyze` 버튼을 눌러 AI의 분석을 봅니다.

**팁**: 브라우저 창을 닫아도 터미널이 켜져 있으면 언제든 `http://localhost:8501` 주소로 다시 접속할 수 있습니다. 끄고 싶으면 터미널에서 `Ctrl + C`를 누르세요.

## 3. 고급 기능 (Advanced Features - New!)
이번 업데이트로 강력한 기능이 추가되었습니다.

### 🔐 향상된 보안 (Advanced PII Masking)
-   이제 단순한 `<PERSON>` 태그 대신, **`<User_a1b2c>`**와 같은 해시 코드로 변환됩니다.
-   **장점**: AI가 사람의 이름은 모르지만, "User_a1b2c가 5분 전에도 접속했었군" 하는 **행동 패턴을 추적**할 수 있습니다. (Context Awareness)

### 🧠 전문가 분석 (Expert Optimization)
-   **Sliding Window**: 긴 로그 파일도 끊김 없이 분석합니다. 중요한 사건이 잘리지 않도록 2,000자씩 겹쳐서 읽습니다.
-   **Verification Loop**: AI가 "데이터 삭제"라고 보고하면, 시스템이 실제 로그에 그 내용이 있는지 한 번 더 **팩트 체크**를 수행합니다.
-   **Structured Output**: 분석 결과가 깔끔한 JSON 표로 제공되며, 영문 답변 후 한글 번역이 자동으로 따라옵니다.
